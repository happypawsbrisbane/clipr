# Coupon Scout AU

## Goal
Build an Australian web app that helps users find the best real savings for online shopping by comparing promo codes, cashback, sales, and related offers.

## Users
Australian online shoppers who want the best checkout savings quickly.

## MVP
- Search stores
- Store pages
- Offer ranking
- User verification reports
- Saved offers dashboard
- Admin moderation view
- Mock data only

## Later
- Browser extension
- Auto-apply coupon testing
- Price alerts
- Affiliate integrations
- Email notifications

## Success
A user can search a store and clearly see the best currently available savings option with a transparent reason why it ranks first.

## v1 scope clarification
Cashback is **out of scope** for v1. The MVP ships coupons and sale/deal offers only. The data schema reserves `CASHBACK` as a future `OfferType` so the model can absorb it later without migration.
