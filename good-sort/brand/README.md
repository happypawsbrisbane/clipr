# GOOD SORT brand asset package

Australian wearables for dogs & humans. Est. 2024.

This package translates the supplied GOOD SORT brand board into a practical digital identity and website asset system.

## Start here

- Use `logos/svg/good-sort-wordmark-oxblood.svg` as the default website header logo.
- Use `logos/svg/good-sort-primary-oxblood.svg` where the tagline has room to breathe.
- Use `logos/svg/good-sort-secondary-oxblood.svg` for square or portrait placements.
- Use `logos/svg/good-sort-symbol-oxblood.svg` for avatars, labels and compact placements.
- Use `logos/svg/good-sort-favicon-oxblood.svg` or `logos/good-sort-favicon.ico` for browser icons.
- Use `colours/good-sort-tokens.css` or `colours/good-sort-tokens.json` to implement the palette.
- Use the four files in `imagery/` for the initial website build.
- Paste `prompt/fable-5.1-website-prompt.md` into Fable 5.1 after attaching the package assets.

## Package contents

- `logos/svg/`: path-based transparent SVG marks in all six brand colours
- `logos/png/`: high-resolution transparent PNG exports in all six brand colours
- `logos/source/`: editable source SVGs
- `patterns/`: transparent monogram repeats in SVG and PNG
- `colours/`: colour swatches, CSS tokens, JSON tokens and GIMP-compatible palette
- `icons/`: lightweight interface icons using `currentColor`
- `imagery/`: four website-ready campaign and collection images
- `copy/`: voice, brand copy, product names and core website copy
- `prompt/`: complete Fable 5.1 implementation prompt
- `reference/`: the original supplied brand board

## Important production note

The supplied reference was a flattened raster brand board, not original vector artwork. The logo files in this pack are a clean digital reconstruction of the visible identity. They are suitable for prototypes, websites and ordinary digital use, but should be checked against the original designer's master vector before trademark filing, manufacturing artwork or very large-format print.

The specified display and body typefaces, Neue Montreal and Suisse Int'l, are commercial fonts and are not redistributed here. Use licensed files if available. Archivo Black and Inter are the recommended web-safe substitutes.

All PNG logo files have transparent backgrounds.
